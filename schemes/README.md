Electromechanical diagrams
====

This directory contains the schematic diagrams of the vehicle's electromechanical components and control software.

## Files

- `communication_diagram.png` — data and communication links between the controllers, sensors and actuators (UART, I2C, PWM, GPIO).
- `power_diagram.png` — power distribution (battery, regulators, motor, servo, controllers and sensors).
- `flowchart_state_machine.png` — obstacle challenge state machine (lane following with entry/exit traffic signs).
