Models
====

This directory contains the 3D CAD models of the vehicle - 27 parts, each provided in two formats:

- **STEP** (`.step`) - the editable CAD geometry, for modification and CNC machining.
- **STL** (`.stl`) - the triangle mesh, ready to print on a 3D printer.

The parts cover the chassis, axles, wheels, bearings, differential, servo and sonar supports, and the gearbox housing.

The full parametric CAD model is available on [Onshape](https://cad.onshape.com/documents/e064973258882f3797ca66b3/w/e97523327652e311225f2991/e/db3f49a87a84e425faee13c2), and the robot's technical datasheet is in the repository root (`robot_profile.pdf`).
